# TFRS
TFRS: Trust-Feasible Relay Selection for Dense NR Sidelink IoT Networks

This repository will hold the MATLAB simulation code, the configuration, the analysis scripts and the result files for the paper:

S. O. Ekwe and J. B. Mwangama, "Trust-Feasible Relay Selection: Trust as an Admission Condition for UE-to-Network Relaying in Dense NR Sidelink IoT Networks," submitted to Telecom (MDPI), 2026.

The files will be released here upon acceptance of the article. Until then, they are available on request from the corresponding author (ekwste001@myuct.ac.za).
